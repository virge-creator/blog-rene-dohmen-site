# René Dohmen's Blog

Personal blog rebuilt from Gatsby to Astro. Features 166+ articles about code, Linux, music, motorcycles, and life.

## Tech Stack

- **Astro** - Static site generator
- **Tailwind CSS** - Styling
- **GitHub Pages** - Hosting

## Development

```bash
npm install
npm run dev
```

## Deployment

Automatically deploys to GitHub Pages on push to `main` branch.

## Content

All blog posts are in `src/content/blog/` as Markdown files with frontmatter.
