Every once in a while I would open up a source file in vim to change
text using the block selection mode, mostly when editing SQL files. Now
I can do it from within [Eclipse](http://www.eclipse.org/) from 3.6 and
above. The block selection mode can be toggled using the toolbar icon in
the top of your editor or using the shortcut key **Alt+Shift+A**. Nice
addition to the Eclipse editor.

I don't know the mac shortcuts. I tried a couple of them, but on a
windows keyboard attached to my mac.
